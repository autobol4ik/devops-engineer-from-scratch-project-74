# DevOps Engineer from Scratch Project 74

[![Actions Status](https://github.com/autobol4ik/devops-engineer-from-scratch-project-74/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/autobol4ik/devops-engineer-from-scratch-project-74/actions)
[![push](https://github.com/autobol4ik/devops-engineer-from-scratch-project-74/actions/workflows/push.yml/badge.svg)](https://github.com/autobol4ik/devops-engineer-from-scratch-project-74/actions/workflows/push.yml)

Docker Engine and Docker Compose 1.27.0 or newer are required.

```sh
make setup
make dev
```

The application is available at http://localhost:8080 and https://localhost.

Run tests with `make test` or `make ci`.

The public image is available on [Docker Hub](https://hub.docker.com/r/autobol4ik/devops-engineer-from-scratch-project-74).
